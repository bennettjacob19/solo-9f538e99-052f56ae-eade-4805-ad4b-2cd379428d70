# 窄带组播补传演练

站台终端在窄带组播中漏收绕行图，本网页用于本地补传演练，并为值班员提供独立的
只读**监看页**，针对窄带线路做了轮询节流、分页与代次隔离。

## 玩法（操作页 `/`）

1. **上传新图**：按 4 KiB 切块，至多 8 块（即 ≤ 32 KiB），末块补零、重组按原长截断。
2. **登记终端**：启用 2~4 台，勾选每台首播实收的块号。
3. **逐轮补传**：每轮设定广播帧数上限和各终端的异或解码额度。一帧发一个
   原块或两块异或；终端实收异或帧、恰缺一块且解码额度未用完时才解回缺块。
   按本轮无丢帧推算，限额内各站都能收齐才选一套方案发送，否则报无方案并
   保留已收块。可注入某台终端漏收本轮某帧。
4. 页面列出实发帧、各站缺块与解码次数；下一轮按各站实收和解回的块继续补传。
5. 每台终端独立拼图，SHA-256 与新图相符才替换可下载的旧图。

## 值班员监看页（`/monitor`，只读）

监看页与操作页隔离：**监看慢或断线不阻塞发帧和下载**（下载在锁外传输）。

- **首屏小载荷**：`GET /api/state` 只回当前进度（各站已收/缺块、校验状态、轮次总数），
  不含轮次明细；`GET /api/rounds` 另取最近 12 轮。
- **两秒内可见结果**：连接正常且内容在变化时每 2 秒轮询一次，发完一轮后两秒内
  显示实发结果与各站进度。
- **空闲节流（每 60 秒最多 6 次）**：连续 60 秒无变化才进入空闲态，节奏拉长到 10 秒，
  并用滑动窗口硬性保证每个 60 秒窗口内自动请求 ≤ 6 次；空闲复轮带 `If-None-Match`，
  命中 `304` 时空体返回，**不重传任何进度或轮次**。内容一变立即恢复 2 秒节奏。
- **断线回来先看最新进度**：重连后立即拉一次 `/api/state`；漏看的轮次按游标分页补看，
  `GET /api/rounds?before=<轮号>&limit=12` 每次最多读回 12 条，服务端只切所需下标，
  **不扫描其他轮**。
- **代次隔离（fencing）**：上传新图、重新登记终端、重置都会推进单调 `generation`。
  监看页持旧代次的迟到回复收到 `409 generation_mismatch` 后整体重装载，
  **迟到回复不会回退进度或混入新轮次**。
- **下载链接防陈旧**：终端下载链接带 `?generation=`。该站换图或重新登记后，
  旧链接返回 `409` 并提示刷新、拒绝下载；无代次参数的直连一律拒绝。

### 接口一览

| 接口 | 说明 |
| --- | --- |
| `GET /api/state?generation=g` | 当前进度（无轮次明细）；`If-None-Match` 命中回 304；代次过期回 409 |
| `GET /api/rounds?generation=g&before=n&limit=k` | 轮次游标分页，`limit` 夹在 1..12，只切 `[before-limit, before)` |
| `GET /terminal/<id>/download?generation=g` | 代次匹配才 200，否则 409 提示刷新 |

## 启动

```bash
docker compose up --build      # 或：pip install -r requirements.txt && python app.py
# 操作页  http://localhost:5000/
# 监看页  http://localhost:5000/monitor
```

## 测试

```bash
python -m pytest tests/ -q      # 后端：切块、规划、漏帧、监看、分页、fencing、并发隔离
node tests/test_poll.js         # 前端轮询器：2s 活跃、60s 空闲≤6 次、恢复、暂停、在途不叠加
```

## 双标签页人工核对要点

1. 标签 A 开 `/monitor`，标签 B 开 `/`。空闲后在 B 连续发多轮：A 应在约 2 秒内
   逐条出现新轮与各站进度，且不重传已见轮次。
2. 在 B 重新登记或换图后，回到 A 点任一终端的旧下载链接：应弹"链接已失效，
   请刷新"并被拒绝（409），刷新后新链接可正常下载。

## 结构

- `planner.py`：切块/重组、BFS 帧序列规划（限帧数+限解码）、轮次执行（含漏帧注入）
- `app.py`：Flask 页面、状态流转、监看 JSON 接口（条件请求/分页/fencing）、代次化下载
- `templates/index.html`：操作页
- `templates/monitor.html`：值班员只读监看页
- `static/poll.js`：可注入时钟的轮询控制器（活跃/空闲两阶段、60 秒 6 次滑动窗口）
- `tests/test_drill.py`：后端测试
- `tests/test_poll.js`：前端轮询器 Node 测试
